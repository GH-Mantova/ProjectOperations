Danger button: one missing CSS rule

Five confirm dialogs use s7-btn--danger: delete dashboard, remove widget, the generic ConfirmDialog, and reject allocation. No CSS rule exists for that class, so the destructive action renders as bare text next to a bordered Cancel. The safe choice looks heavier than the dangerous one. Below is the same dialog as it ships, with the proposed fix and the alternative.
