Quote PDF: six fixes to the signed-off design

Each pair below is the same part of the same quote, before and after. Highlighted text is what changes. Nothing else on the PDF moves: same pages, same order, same fonts, same totals. The quote screen doesn't change either (section 5). The two choices are recorded at the bottom.

"Date" is the day the quote was sent, so it never changes. A quote not yet sent shows today's date, as it does now. "Printed on" in the grey strip stays the print date: that's the document-control stamp, and it should change.

The wording is unchanged; only the line breaks that are already in the terms text now print. This matters most for the a)/b)/c) list that defines how a client accepts.
