The preview paints itself only — it never touches the page around it. A failing pair warns; it does not block saving. "Unknown" is shown when a colour is missing or invalid, never a made-up number.

This palette applies in light mode. Dark mode keeps the built-in theme, so switching to dark still gives a readable screen whatever the company palette says.

Everything is visible — palette, preview, contrast grades — and nothing is editable. One line says why: brand changes need a super-user account. No control is shown that would fail on save.

Deleting the company default is refused. "Default" cannot be deleted at all. Any other scheme deletes behind a confirmation that names what happens. A scheme that is currently the company default must be replaced first — deleting it would silently return everyone to the built-in theme.

3What this screen does not yet do

Brand files are links, not uploads. The four brand files — logo light, logo dark, favicon, PDF letterhead — are set by pasting a link. Drag-and-drop upload is a separate, open decision: it needs somewhere to store files, which the system does not have yet.
A preset sets colours, and only colours. Graphite and Harbour change the palette. They do not change corner radius, type or spacing, so Graphite will not look like the sharp-cornered industrial theme in the older mock-up. Per-scheme shape and typography is a separate, open decision.

Both are listed here rather than left to be discovered on the screen. Neither of them blocks this slice, and neither is closed by shipping it.
