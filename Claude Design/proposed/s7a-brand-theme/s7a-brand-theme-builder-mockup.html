Brand and theme

Settings › Company › Brand & theme — the screen that replaces the six legacy text inputs. It edits the colour schemes that already exist in the database, previews them, grades their contrast, sets the company default, and keeps the four brand file links editable. Every figure is an example.

Unsaved changes

Two separate actions on purpose. Editing a scheme never makes it the company default, and making it the default never saves an edit you were still working on.

A half-typed hex blocks saving and never reaches the server. This is a different thing from a colour that is valid but hard to read, which only warns.

Delete

Deleting Graphite — it is not the company default, so it can go. Anything using it falls back to the built-in theme.

The company default cannot be deleted, and "Default" cannot be deleted at all. To remove the scheme in use, make another one the default first.

3What this screen does not yet do

Brand files are links, not uploads. The four fields above take a URL, which is what the system can store today. Drag-and-drop upload is a separate, open decision: it needs somewhere to keep files, which does not exist yet.
A preset sets colours, and only colours. Graphite and Harbour change the palette. They do not change corner radius, type or spacing, so Graphite will not look like the sharp-cornered industrial theme in the older mock-up. Per-scheme shape and typography is a separate, open decision.

Both are listed here rather than left to be discovered on the screen. Neither of them blocks this slice, and neither is closed by shipping it.
